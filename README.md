# College Store

A React + Vite college ecommerce navigation demo using React Router DOM.

## Run in VS Code

1. Install Node.js 22 LTS or a newer supported LTS version.
2. Extract the ZIP and open the college-store folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the localhost URL printed in the terminal.

The site demonstrates product browsing and navigation, not checkout or payment.
